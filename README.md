## 🏗️ Featured Projects

### ⚡ [CNN Accelerator on FPGA — DIR-V Grand Challenge](https://github.com/anujgite10-10/cnn_accelerator)
Quantized LeNet CNN accelerator in Verilog on Xilinx Artix-7. MicroBlaze soft-processor + AXI DMA + custom Conv3×3/ReLU inference engine.
- **>91% accuracy** · **<500ms inference** · **<60% FPGA utilization**
- Top 100 / 1392 teams — DIR-V Grand Challenge (C2S, MeitY, Govt. of India)

### 🧠 [NeurISA — RISC-V Custom ISA Extensions for CNN Acceleration](https://github.com/VLSI-TECH-WITH-ANOUSHKA/sakec-chipmonk-hackathon-troubleshooters)
12+ custom SIMD INT8 instructions on NEORV32 RISC-V core with hardware CNN accelerator on Zynq-7000.
- **13× inference speedup** for LeNet · HW/SW co-design · UVM verification

### 🌾 [Agentic AI FPGA-Accelerated Smart Agriculture](https://github.com/navya-sinha-dot/Google_Solution_challenge) · [Live Demo](https://google-hack-kgp5.vercel.app/)
Edge AI system on AMD Zynq-7000 with Vitis HLS rain prediction & sensor fusion accelerators + LoRa communication.
- **4.22× faster inference** vs CPU · 🥈 Google Solution Challenge 2026
